# 전략 차트 이식 검증

2026-09-11 · Lightweight Charts 5.2.1

**[index.html](index.html)을 브라우저에서 열면 볼린저 차트가 바로 표시됩니다.** 상단에서 전략 A–K, 롱·숏, 평단선을 선택하고 확대할 수 있습니다. 설치나 서버 실행 없이 이 폴더의 `index.html`과 `app.js`로 동작합니다.

## 확인 범위

기존 `frontend/src/lib/indicators.js`의 계산 결과를 테스트용 캔들 데이터와 함께 연결했습니다. `app.js`에는 검증 당시 계산 코드와 차트 라이브러리가 포함돼 있습니다. 실제 시세 API에 접속하지 않습니다.

- A–K 대표 설정 × 롱·숏 × 평단선 유무 × PC·모바일: 88개 조합 통과.
- 원거리 지정가, 큰 볼린저 밴드, 볼린저 돌파, SMA, 기하 그리드 × PC·모바일: 추가 10건 통과.
- 지표 수치 보존, 마커의 봉 시간 대응, 볼린저 확대 후 좌표 대응, RSI 보조창·영역, 캔들이 납작해지는 현상을 막는 축 범위 처리를 확인했습니다.
- C 정기 분할매수는 원래 가격선이 없어, 차트에 별도 전략선이 나타나지 않습니다.

[상세 검증 결과](report.json)

이 예제는 이식 가능성을 확인하는 프로토타입입니다. 실제 페이지에 통합할 때 실시간 증분 갱신, 확대 위치 유지, 라벨 겹침, 모바일 터치·접근성을 검증해야 합니다. 현재 사이트의 차트 교체나 매매 엔진 검증을 완료했다는 의미는 아닙니다.
