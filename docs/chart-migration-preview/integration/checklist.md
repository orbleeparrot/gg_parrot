## 전략

`frontend/src/lib/indicators.js`의 계산값을 그대로 렌더링해야 한다. 모든 전략을 롱/숏 양쪽, 내 평단 유무로 확인한다.

| 방식 | 표시 항목 |
| --- | --- |
| A | 현재가, 익절선, 선택적 손절선, 가격선 라벨·범례·설명 |
| B | 지정 진입·청산 가격선, 롱/숏 주문 방향에 맞는 라벨·색상 |
| C | 정액 매수 방식 안내(가격선이 없는 것이 정상) |
| D | 산술·기하 그리드 가격선, 범위·간격 안내 |
| E | 트레일링 선, 선택적 하락 진입 조건, 라벨·범례 |
| F | RSI 선, 0–100 범위, 과매수·과매도 음영/점선/수치/의미, 매매 삼각형 |
| G | BB 상·중·하단선과 음영, 반등/돌파 방식의 매매 삼각형 |
| H | 안전 주문 단계와 익절선 |
| I | 변동성 돌파 기준선과 교차 매매 삼각형 |
| J | SMA/EMA 단·장기선과 교차 매매 삼각형 |
| K | 방어전 가격선과 각 방향 익절·손절선 |
| 실행 세션 | 전략 전체 + 내 평단 점선/라벨/범례, 매크로 없는 예전 세션의 평단 단독 표시, 무포지션의 전략 단독 표시 |

공통: null 지표 구간을 연결하지 않는다. 선 색·굵기·점선 패턴, 음영, 라벨 겹침 처리를 보존한다. 매매 마커는 **entry/exit가 아니라 buy/sell 기준**으로 아래의 상승 삼각형/위의 하락 삼각형을 정한다. 가격선이 시세와 멀 때에는 기존의 가격 축 확장 한도(봉 가격 폭의 양쪽 1.5배)를 적용하여 봉을 납작하게 만들지 않는다. 테마 변경 시 캔버스 색도 갱신한다.

## 자산 곡선

- 데이터가 2개 미만일 때의 빈 상태.
- 모든 자산 값, 시작/최종 날짜와 금액을 호버 없이도 읽을 수 있는 캡션.
- 상승/하락의 테마색, 하단 음영, 초기 자본 점선, 최종 점 강조.
- 포인터 및 키보드 좌우 선택, 선택 날짜·금액, 교차선·선택 점.
- `height`, `stretch`와 반응형 높이, 테마 변경, 데이터를 갱신하거나 비웠다가 다시 채워도 정상 표시.
- 중복 시각·같은 날짜의 여러 값에서 값이 조용히 사라지지 않음.

## 검증 범위의 한계

기존 studio의 OHLC는 그림에 겹쳐 있었으나 이식 후 차트 바로 위로 옮겼다. 모바일에서 가격·전략선과 읽기 값이 겹치지 않도록 한 배치 변경이며, 항목은 그대로 유지한다. 모바일 studio 그림은 일반 240px, RSI 포함 350px 이상을 확보한다.

브라우저 검증은 실제 React 컴포넌트와 지표 함수를 사용하되 모든 API를 가로채 만든 시세로 실행한다. 실거래 키·사용자 데이터·공유 데이터베이스에는 쓰지 않는다. 차트 이식의 검증이며 매매 엔진의 수익성이나 실제 체결을 검증하는 것은 아니다. 픽셀 단위 결과는 브라우저/DPR에 따라 달라질 수 있으므로 데이터와 조작 검증, 스크린샷 육안 확인을 함께 사용한다.

## 표시 방식 변경

SVG 캔들에 붙이던 시가·종가 짧은 눈금은 네이티브 캔들의 몸통 경계와 OHLC 읽기로 전달한다. 수치는 그대로다. 직접 만들기 화면의 OHLC는 캔들 위에 겹치지 않도록 그림 바로 위에 배치했다. 오른쪽 가격 축과 아래 시간 축은 네이티브 차트가 제공한다.
