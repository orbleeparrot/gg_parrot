# 차트 등락 표시와 하단 행 정리

- 상단에 `구간 등락`을 붙여 화면에 보이는 첫 봉의 시가 대비 마지막 봉의 종가 변화임을 표시했습니다.
- 별도 하단 날짜·실시간 상태 행을 제거했습니다. 차트 시간 축, OHLC, LIVE와 전략 표시는 유지했습니다.
- 모바일에서 차트가 화면 너비를 넘지 않도록 조정했습니다.

검증 화면: [PC 1440px](chart-labels-1440.png), [모바일 390px](chart-labels-390.png)

스크린샷은 실제 `/builder` 페이지에 검증용 시세를 주입해 촬영했습니다. 실제 시장 가격이 아닙니다. 큰 가격 숫자에서의 줄바꿈과 가격 축 잘림도 확인했습니다.

Chromium에서 4가지 차트 형태와 `/builder`, `/agents`를 두 화면 너비로 확인했습니다. 12개 검사 및 프런트엔드 빌드가 통과했습니다. [검사 결과](report.json)
