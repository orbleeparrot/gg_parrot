# 가격 강조와 LIVE 정렬

- 가격: PC 32px, 모바일 28px. 티커는 13px, 퍼센트는 15px로 표시합니다.
- 가격과 단위를 묶고, `구간 등락`은 퍼센트 오른쪽의 보조 정보로 옮겼습니다.
- `진행 중` 배지를 제거하고 LIVE를 OHLC 행 오른쪽으로 옮겼습니다.
- OHLC가 여러 줄이면 LIVE를 마지막 줄에 맞춥니다. 정보 행의 위아래 여백은 8px입니다.

실제 페이지 화면: [직접 만들기 PC](builder-1440.png), [모바일](builder-390.png), [내 에이전트 PC](agents-1440.png), [모바일](agents-390.png)

실제 페이지에 검증용 시세를 주입해 촬영했습니다. 실제 시장 가격이 아닙니다.

두 화면 너비에서 4가지 차트 형태와 실제 2개 페이지, 최신·과거 구간 전환을 확인했습니다. 글자 크기, 문구 순서, 오른쪽·하단 정렬, 여백, 화면 밖 잘림 검사 및 프런트엔드 빌드가 통과했습니다. [검사 결과](report.json)
