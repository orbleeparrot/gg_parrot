# 헤더 아이콘 조사와 적용

조사일: 2026-09-09. 적용 범위: 실행기 설치, 사용법, 테마 전환, 프로필.

## 공식 자료에서 확인한 기준

### 1. 그림 크기와 클릭 영역은 별도 치수다

[Carbon의 아이콘 가이드](https://carbondesignsystem.com/elements/icons/usage/)는
16·20·24·32px 아이콘을 구분한다. 16·20px는 14·16px 텍스트와 조합하고,
더 큰 기능 아이콘이 필요한 경우 24·32px를 사용한다. 터치 영역은 44px 이상으로
확보하며, 작은 그림 주위에 CSS 패딩을 넣는 예시를 제공한다.

[Material Web의 아이콘 버튼](https://material-web.dev/components/icon-button/)은
기본 그림 크기를 24px로 정의한다. 채움·외곽선 버튼의 기본 컨테이너는 40×40px이고,
기본형 버튼은 배경과 테두리 없이 낮은 강조도로 사용한다.

두 자료의 수치는 각 시스템의 규격이다. 웹 전체에 적용되는 단일 정답으로 취급하지 않는다.
[WCAG 2.2의 최소 타깃 기준](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)은
예외 조건을 포함한 24×24 CSS px이며, 아이콘 그림의 최소 크기를 뜻하지 않는다.
이번 헤더는 최소 통과 여부와 별개로 실제 클릭 영역을 44px 높이로 확보한다.

### 2. 익숙한 도상과 일정한 스타일을 사용한다

[Fluent의 아이콘 가이드](https://fluent2.microsoft.design/iconography)는
알아보기 쉬운 기능적 도상을 권장한다. Regular는 다운로드 같은 동작을 안내하고,
Filled는 선택 상태나 작은 크기의 강조에 사용할 수 있다. 복잡한 수식 도형과 불필요한
색을 피한다. 상태 의미가 없는 곳에서 채움·윤곽선을 임의로 섞지 않는다.

이번 헤더는 이미 설치된 Phosphor의 regular 원본으로 통일한다.
다운로드 화살표 / 원 안의 물음표 / 해·달 / 사람 윤곽을 사용한다.
리소스 링크는 아이콘과 기능명을 함께 보여 준다. 프로필은 사용자가 요청한 대로
아이콘만 표시하고, 비로그인은 로그인 화면으로 바로 이동한다.

### 3. SVG 외곽 크기가 같아도 눈에 보이는 크기는 다르다

[Google Material Symbols 문서](https://developers.google.com/fonts/docs/material_symbols)는
20–48dp optical size 축으로 표시 크기에 맞춰 획을 조정한다. 이는 해당 폰트의 기능이며,
모든 SVG가 같은 보정을 자동으로 제공한다는 뜻은 아니다.

따라서 Phosphor에서는 `width`만 확인하지 않고 원본 viewBox 안의 도형 범위,
실제 화면에서의 크기와 정렬을 함께 확인한다. 18px SVG 안에 여백까지 들어가면
기능 아이콘이 더 작게 보인다. 이번에는 테마·프로필 SVG를 28px로 키운다.
28px는 이 제품에 적용한 디자인 판단이며 외부 표준의 의무 수치가 아니다.
SVG의 path·fill·stroke는 라이브러리 원본을 유지한다.

### 4. 대비·레이블·상태도 함께 설계한다

[Fluent의 버튼 가이드](https://fluent2.microsoft.design/components/web/react/core/button/usage)는
동등한 보조 기능에 중성·투명 배경을 사용하고, 텍스트 4.5:1·아이콘 3:1의 대비를
확보하도록 안내한다. 이번 헤더는 기존 테마의 본문 전경색을 사용하고, hover·현재 경로·
열림 상태에서만 작은 중성 배경을 표시한다. 키보드 포커스 외곽선은 유지한다.

아이콘 자체는 장식으로 숨기고 링크·버튼에 접근 가능한 이름을 둔다.
테마 전환은 현재 상태와 다음 동작을 알린다. 좁은 화면에서 라벨을 감추더라도
아이콘·접근 가능한 이름·포커스 시 툴팁을 유지한다.

## 적용 규격

| 요소 | 그림·텍스트 | 클릭 영역 | 상태 배경 |
|---|---|---|---|
| 실행기 설치·사용법 | 20px 아이콘 + 14px 라벨, 사이 6px | 두 링크 모두 104×44px | 104×36px |
| 테마·프로필 | 28px 아이콘, regular | 44×44px | 40×40px |
| 479px 이하 설치·사용법 | 24px 아이콘, 라벨은 툴팁 | 44×44px | 40×40px |

같은 그룹 안의 간격은 4px, 그룹 사이는 8px다. 479px 이하에서는 그룹 사이도 4px로
줄여 320px 화면에 네 기능을 모두 배치한다. 480px부터는 설치·사용법 라벨을 함께 표시한다.
배경을 크게 칠하는 대신 그림의 가독성과 클릭 영역을 각각 확보한다.

## 프로젝트 기준과의 관계

`DESIGN.md`의 기존 색·타이포그래피·메뉴 구조를 유지한다. 사용자 위키의
`concepts/ui-디자인-원칙.md`(일관성, 대비, 여백),
`concepts/gui-위젯-10요소.md`(익숙한 아이콘, 공간이 되면 라벨 병기)를 적용한다.
디자인 시스템 전체나 새 아이콘 패키지를 도입하지 않는다.

검증은 라이트·다크, 로그인 전후, 320–1686px 화면에서 실제 렌더링과 클릭 동작을
확인한다. 인증 화면과 회원 데이터는 로컬 API fixture를 사용한다.
