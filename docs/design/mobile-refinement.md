# 모바일 화면 구성 보완 · 2026-09-10

이번 수정은 기존 껄무새의 색·서체·브랜드 자산을 유지하며, 작은 화면에서 정보와 행동을 읽는 순서를 바꾸는 작업이다. Apple/Google의 네이티브 앱 원칙을 웹 UI에 참고했다. 해당 기업의 공식 컴포넌트를 사용하거나 디자인을 그대로 복제한 것은 아니다.

## 참고한 기준

- [Apple HIG — Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons?changes=latest_1__8): 서로 관련된 버튼의 크기는 일관되게 유지하고, 중요도는 스타일로 구분한다. 터치 영역과 시각적 위계를 함께 고려한다.
- [Google — Touch target size](https://support.google.com/accessibility/android/answer/7101858?hl=en): 아이콘의 보이는 크기와 실제 터치 영역은 다르다. 작은 아이콘 때문에 배경 박스까지 크게 만들 필요는 없다.
- [Google — List/detail adaptive layout](https://developer.android.com/develop/adaptive-apps/guides/list-detail): 좁은 화면에서는 모든 패널을 동시에 축소하기보다 주요 정보와 상세를 순서대로 보여준다.
- 내부 `design-catalog`의 Toss 명세 중 목록 행·목록 제목 구성: 식별 정보는 왼쪽, 금액·결과는 오른쪽에 정렬한다. 이는 내부 참고 자료이며 공식 배포 컴포넌트 검증을 대신하지 않는다. 색 토큰은 복사하지 않았다.

## 적용

- 헤더: 사용자 요청대로 테마 토글을 프로필 바로 왼쪽에 둔다. 두 컨트롤은 각각 44px 터치 영역을 확보하며, 사용법·설치 링크는 메뉴에 둔다. 터치 기기에 호버 툴팁을 띄우지 않는다.
- 홈: 모바일 게시판 소개는 제목·게시글 예시 3개·게시판 링크로 제한한다. 반복 소개와 가짜 페이지 번호를 없앤다.
- 코인동향: 제목 옆 설명을 공통 `InfoTooltip`으로 통일한다. 원형 외곽 박스 대신 16px 정보 아이콘을 쓰고, 투명한 터치 영역을 넓힌다. 터치로 열고 다시 누르거나 바깥을 누르면 닫힌다.
- 리더보드: 순위·코인·심볼·수익률은 한 줄, 전략과 작성자·시각·배지는 4px 간격의 한 묶음으로 둔다. 반복 라벨과 큰 버튼 박스를 없애고, 하단에는 18px 아이콘과 12px 숫자만 남긴다. 32px 컨트롤 바깥의 투명한 터치 영역은 최소 44px이며 서로 겹치지 않는다. 잠금 해제는 자물쇠와 포인트 가격으로 표시한다.
- 채팅: 모바일은 오른쪽 아래 고정 버튼이다. 데스크톱에서 저장한 위치는 모바일에 적용하거나 덮어쓰지 않는다.
- 프로필: 사용자 정보와 수치를 먼저 보여주고, 계정 설정은 접어서 둔다. 활동 다섯 종류는 선택 입력으로 전환한다. 모바일 내역에는 수치의 의미를 표시하며, 편집·비밀번호 변경·탈퇴 기능을 유지한다. 긴 숫자는 지표 전체를 라벨 왼쪽·금액 오른쪽 목록으로 바꿔 읽는다.

CSS px는 네이티브 pt/dp와 동일한 단위라는 가정을 하지 않는다. 실제 웹 레이아웃의 클릭 영역, 글자 줄바꿈, 긴 값, 세로/가로 화면과 다크/라이트 테마를 브라우저에서 확인한다.
