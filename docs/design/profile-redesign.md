# 프로필 리디자인

2026-09-10 · `/mypage`

이 화면은 껄무새 회원이 자신의 매크로·구매·판매·포인트·게시글을 확인하고 계정을 관리하는 곳이다. 벤치마크의 목적은 다른 회사의 프로필 모양을 고르는 것이 아니라, 각 기능을 어디에 놓고 어떤 정보까지 처음부터 보여 줄지 판단하는 것이다.

## 직접 확인한 화면

공개 프로필을 Chromium으로 실제 열어 1280px와 390px에서 캡처하고, 이미지와 DOM의 치수를 함께 확인했다. 로그인하지 않은 공개 화면이므로 본인 계정의 설정 동작까지 관찰한 것으로 해석하지 않는다.

| 출처 | 관찰 | 껄무새에 적용할 판단 |
| --- | --- | --- |
| [Pinterest](https://www.pinterest.com/pinterest/) | 데스크톱 사진120px, 이름28px, 작은 팔로워 수치와 행동을 신원 블록 안에 배치 | 사진·신원·수치·편집이 같은 회원에게 속한다는 것을 한 번에 읽게 한다 |
| [TradingView](https://www.tradingview.com/u/TradingView/) | 데스크톱 사진168px·이름36px·수치20px, 모바일 사진56px·수치18px. 사진 옆의 신원·통계와 아래 활동 탭 | 이름보다 조용한 수치, 동일 기준선, 기기 너비에 맞춘 정보 순서 |
| [GitHub](https://github.com/yyx990803) | 데스크톱296px 신원 레일·이름24px. 모바일60px 사진, 소개·작은 통계·32px 행동, 밑줄 탭 | 프로필 편집과 활동 탐색의 역할을 구분하고, 활동 분류를 바로 보이게 한다 |
| [Pinterest 공식 가이드](https://create.pinterest.com/en-gb/get-started/) | 프로필 사진·소개·수치·Edit Profile을 묶은 앱 예시 이미지 제공 | 사진과 편집의 관계를 확인하는 보조 자료. 현재 공개 웹 화면과는 구성이 다름 |

공개 프로필의 커버·팔로워·기여 그래프는 껄무새에 없는 기능이다. 해당 외형을 채우기 위해 추가하지 않는다. 기존 앱 사이드바, 브랜드색, Pretendard·JetBrains Mono, 모바일 PWA 탐색 흐름은 유지한다.

## 기능별 위치와 노출

| 기능 | 기본 화면 | 열거나 선택했을 때 |
| --- | --- | --- |
| 사진·이름·소개 | 회원 신원을 한 묶음으로 표시, 사진과 별도 편집 버튼 모두 제공 | 같은 프로필 편집 창에서 사진·이름·소개를 저장 |
| 보유 포인트·판매 수익·누적 판매 | 같은 크기·기준선, 보유 포인트만 브랜드색. 사진·이름 가까이에 묶음 | 큰 수치는 모바일에서 모두 같은 목록 배치로 전환 |
| 판매 등급 | 이름 옆 현재 등급만 작은 SVG와 이름으로 표시 | 다음 조건과 전체 단계 |
| 만든·구매한 매크로 | 활동 탭과 개수를 바로 표시, 기본은 만든 매크로. 매크로가 있어도 목록 위에서 새로 만들기 제공 | 목록에서 전략·판매 수익·등록/구매 시각을 확인하고 빌더로 열기/복사 |
| 판매·포인트 내역·게시글 | 같은 활동 탐색에서 직접 선택 | 해당 목록만 표시, URL 상태 유지 |
| 계정 설정 | 편집 옆 버튼 | 이메일·가입 방식, 비밀번호 변경(가능한 계정), 로그아웃·탈퇴 |
| 탈퇴 | 설정 안에서만 제공 | 확인 문구와 비밀번호 또는 Google 재인증 등 기존 절차 |

모바일에서 활동 다섯 종류를 select 안에 숨기지 않는다. 밑줄 탭을 가로로 넘기며, 넘치는 경우에만 오른쪽 화살표로 다음 가려진 활동을 선택할 수 있다. 끝에서는 화살표를 비활성화한다. URL 직접 진입·새로고침·키보드 이동에서도 선택 탭이 보이게 한다. 탭을 보여 주기 위해 본문까지 위로 스크롤하지 않는다.

매크로 목록은 코인·전략과 판매/수익/등록일을 묶고, 행동은 같은 행의 오른쪽에 놓는다. 사진 아래의 빈 열을 여러 줄에 걸쳐 유지하지 않는다. 모바일 버튼의 보이는 면은36px, 누를 수 있는 영역은44px로 구분한다.

## 원칙과 검증

팀 위키 `concepts/ui-디자인-원칙.md`의 근접성·위계·일관성·불필요한 테두리 제거와 `concepts/프로필-페이지-디자인-관례.md`의 이름·등급·메타·활동 분류를 실제 화면과 대조했다. 위키의 과거 적용 예시보다 사용자가 이후 요청한 동일 크기 수치·브랜드색·접힌 등급을 우선한다.

고정된 로컬 API 응답으로 검증한다.

- 너비320·375·390·414·768·844·1440px, 라이트·다크의 실제 화면.
- 긴 이름·큰 수치·사진·빈 활동, 숫자 기준선과 문서 가로 넘침.
- 다섯 활동과 URL 복원, 가로 탭의 선택 항목 노출, 포인터·키보드 전환과 본문 스크롤 유지.
- 프로필 저장·취소·실패·뒤늦은 응답, 비밀번호 변경, 일반/Google 계정 탈퇴와 로그아웃.
