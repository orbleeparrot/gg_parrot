# 프로필과 설정 화면 재설계

2026-09-10 · `/mypage` · `/mypage/settings`

프로필은 회원의 매크로와 포인트 활동을 탐색하는 공간이다. 사진·이름·소개는 회원 영역에, 작업과 기록은 콘텐츠 영역에 놓는다. 편집과 계정 관리는 전용 설정 페이지로 이동한다.

## 참고 화면에서 가져온 판단

사용자가 제공한 Spotify·DACON·Kaggle·Higgsfield·SIR 프로필 화면과 모바일 디자인 예시를 직접 비교했다. 사진·이름의 큰 묶음, 작업 영역과 관리 기능의 분리, 현재 선택한 종류만 보여 주는 탐색을 참고했다.

| 구성 판단 | 껄무새에서의 구현 |
| --- | --- |
| 신원과 작업을 별도 영역으로 구성 | 데스크톱의 왼쪽 회원 영역 + 오른쪽 작업 공간 |
| 모바일에서 신원은 위에, 작업은 아래에 배치 | 가운데 사진, 이름·등급 한 줄, 아래 가입일 |
| 편집과 보안은 설정에서 관리 | 오른쪽 위 톱니바퀴로 설정 진입, 중복된 프로필 편집 링크 제거 |
| 통계는 나란한 열, 같은 크기와 기준선 | 보유 포인트·판매 수익·누적 판매를 같은 규격으로 표시 |
| 작업은 내용을 비교하며 선택 | 코인·전략·판매/구매 정보·빌더 행동을 담은 매크로 카드 |
| 드문 관리 항목은 필요할 때 접근 | 비밀번호 변경·로그아웃·탈퇴는 설정의 계정 및 보안에서 제공 |

팔로워·경력·리뷰·임의의 썸네일 등 이 서비스에 없는 데이터는 추가하지 않는다. 기존 공통 헤더·사이드바, 브랜드색과 서체를 사용한다. 프로필에서 회원 영역·포인트 요약·매크로를 면으로 묶는 것은 이번 전면 재설계에 따른 `DESIGN.md`의 페이지 예외다.

이전 조사에서 직접 확인한 공개 화면은 [Pinterest](https://www.pinterest.com/pinterest/), [GitHub](https://github.com/yyx990803), [TradingView](https://www.tradingview.com/u/TradingView/)다. 로그인하지 않은 공개 화면과 본인 계정 설정을 동일한 화면으로 취급하지 않는다.

## 프로필

- **회원 영역:** 사진, 이름, 현재 판매 등급, 소개, 가입일. 우상단 톱니바퀴로 설정을 열어 프로필을 편집한다. 사진에서도 편집 화면으로 이동할 수 있다.
- **회원 기능:** 가입일 아래 로그아웃을 배치한다. 회원 키는 설정 → 계정 및 보안의 관리 버튼으로 펼쳤을 때만 조회하며 기본 마스킹, 보기·복사·재발급을 제공한다. 계정이나 설정 탭이 바뀌면 열린 키를 초기화한다. 헤더 아바타는 드롭다운 없이 프로필로 바로 이동한다.
- **포인트 요약:** 세 수치에 같은 숫자 크기와 행 높이를 적용한다. 보유 포인트는 브랜드색이다. 긴 숫자는 세 수치를 함께 세로 정렬한다. 각 수치에서 해당 내역으로 이동한다.
- **매크로:** 만든/구매한 매크로 두 필터와 개수, 카드 목록, 새로 만들기. 만든 카드에는 판매 건수·수익, 구매한 카드에는 실제 구매 금액·구매일을 표시한다. 사용할 수 없는 매크로는 비활성 행동과 짧은 상태로 구분한다.
- **포인트·판매:** 판매 내역과 포인트 원장 두 필터. 내용·회원·날짜는 왼쪽, 증감과 잔액은 오른쪽으로 맞춘다. 두 내역의 개수를 합산하지 않는다.
- **게시글:** 제목, 댓글 수, 첨부 여부와 날짜, 글쓰기.
- **판매 등급:** 현재 등급만 표시하고 전체 조건은 별도 대화상자에서 확인한다.

기존 `?tab=created|purchased|sales|ledger|posts` 주소를 유지한다. 상위 분류와 하위 필터가 함께 복원된다. 하위 필터는 방향키·Home·End로 이동하며 가로 스크롤을 요구하지 않는다.

600px 미만에서는 프로필의 보조 행을 합치고, 중복된 매크로 제목을 시각적으로 숨긴다. 두 필터 옆의 + 버튼으로 새 매크로를 만든다. 접근 가능한 이름과 본문 제목 연결은 유지한다. 매크로는 한 열, 넓은 화면에서는 두 열이다.

## 간격과 정렬

`DESIGN.md`의 4px 배수 규칙을 프로필 전체에 적용한다. `MyPage.css`의 페이지 변수에서 박스 안쪽 여백·영역 간격·정보 묶음·라벨 간격을 관리한다.

- 박스 안쪽은 기본 24px, 모바일과 좁은 데스크톱은 16px. 주요 영역 사이는 PC 24px, 모바일 16px이다.
- 이름·소개·가입일·회원 기능 같은 묶음 사이는 16px, 라벨과 값 사이는 8px, 종목과 보조 정보 사이는 4px이다. 자식의 개별 마진을 중첩하지 않는다.
- 포인트 요약은 같은 라벨 행과 숫자 행을 쓴다. 매크로의 금액·구매일도 20px 행 높이와 같은 숫자 크기를 사용한다.
- 나란한 매크로 카드의 제목·전략·수치·버튼 행은 subgrid로 맞춘다. 긴 설명은 전부 표시하며 같은 줄의 카드끼리 필요한 높이를 공유한다. 미지원 브라우저는 카드 내부 grid로 표시한다.
- 판매·포인트·게시글 목록은 첫 행부터 상하 16px 패딩이다. 거래 제목과 증감은 첫 행에서 정렬하고, 날짜·잔액은 8px 아래에 놓는다.

## 설정과 편집

`/mypage/settings`는 데스크톱 200px 탐색 + 최대 640px 폼, 모바일은 위쪽 두 항목 탐색 + 전폭 폼이다.

- **프로필:** 96px 사진과 변경·삭제, 프로필명, 소개. 저장 후 같은 페이지에 남고 저장된 값을 기준으로 편집 상태를 초기화한다. 취소는 프로필로 돌아간다. 모바일 진입 시 입력을 자동으로 선택하지 않는다.
- **계정 및 보안:** `?tab=security`. 이메일·가입 방식, 비밀번호 변경(설정 가능한 회원), 회원 키 관리, 로그아웃, 회원 탈퇴.
- 비밀번호·탈퇴는 전용 대화상자의 기존 검증·재인증 절차를 따른다.
- 사진 선택·삭제는 저장 전까지 공개 프로필에 반영되지 않는다. 계정 변경 뒤 이전 응답이 새 회원 정보를 덮지 못하게 한다.
- 오래된 저장 정보에 소개·가입 방식 등이 없으면 최신 계정을 받은 뒤 편집 폼을 연다. 불완전한 초깃값으로 기존 소개를 지우지 않는다.

## 검증

로컬 API fixture와 실제 Chromium으로 검사한다. 운영 계정이나 거래를 변경하지 않는다.

- 320·375·390·414·768·844·1440px, 밝은/어두운 테마.
- 전체 구조, 긴 이름·큰 수치·긴 전략, 숫자와 카드 하단 정렬, 가로 넘침.
- 세 분류와 두 필터, URL 직접 진입·새로고침·키보드 이동, 등급 대화상자.
- 설정 진입·복귀, 사진과 이름·소개 저장·취소·실패, 늦은 응답과 계정 전환.
- 비밀번호 변경과 일반/Google 회원 탈퇴, 미완성 캐시의 소개 보존.
