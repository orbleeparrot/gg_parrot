# 프로필 리디자인

2026-09-10 · `/mypage`

기존 화면에서는 등급 안내와 계정 설정이 신원과 활동 사이를 차지했고, 모바일 매크로 한 항목이 판매·수익·날짜·버튼 때문에 여러 줄로 늘어졌다. 사용자가 보는 순서를 신원 → 포인트·판매 통계 → 활동으로 정리했다.

## 적용 근거

- 팀 위키 `concepts/ui-디자인-원칙.md`: 관련 정보는 근접하게 묶기, 같은 기능은 같은 형태로 표현하기, 장식용 테두리 제거, 색에 의미 부여하기.
- 팀 위키 `concepts/프로필-페이지-디자인-관례.md`: 이름이 제목, 이름 옆의 작은 등급, 한 줄 메타, 상자 없는 통계, 개수를 붙인 활동 탐색, 전체 폭 목록.
- `hallmark`의 redesign 및 responsive·interaction·slop-test 규칙: 기존 앱의 디자인 시스템과 기능 유지, 모바일에서 실제 렌더링 확인, 키보드·펼침 상태 제공, 의미 없는 모션과 설명 제거.

위키의 9월 9일 적용 예시에는 포인트만 더 큰 수치와 처음부터 펼친 등급 사다리가 있지만, 이후 사용자가 요청한 동일 크기 수치·브랜드색·접힌 등급을 우선했다. Hallmark의 신규 사이트용 테마 교체·글꼴 추가·토큰 내보내기는 적용하지 않고, 잠긴 앱 시스템 `DESIGN.md`와 `index.css`의 기존 토큰을 따른다.

## 화면 결정

- 신원과 통계를 서로 다른 행에 둔다. 통계는 글자 크기와 기준선을 같게 하고, 보유 포인트만 브랜드색이다. 데스크톱의 통계는 화면 전체에 흩어지지 않도록 64px 간격으로 묶는다.
- 현재 등급을 누르면 다음 조건과 다섯 단계를 펼친다. 계정 설정도 상단 버튼으로 필요할 때 연다. 두 기능은 버튼의 `aria-expanded`와 `aria-controls`로 상태를 전달한다.
- 프로필 편집은 사진과 별도 버튼 양쪽에서 진입한다. 긴 이름과 편집 버튼이 좁은 한 행에서 폭을 다투지 않는다.
- 데스크톱은 밑줄 탭, 모바일은 외곽 상자를 뺀 기본 선택 입력이다. 검색·필터처럼 보이는 장식을 추가하지 않는다. 다섯 분류와 개수·URL을 유지한다.
- 모바일 매크로는 정보 묶음과 행동 버튼을 같은 하단 행에 둔다. 버튼 문구를 줄바꿈하지 않는다.
- 편집·비밀번호·탈퇴 창, 계정별 권한, 저장 경합 방지, 회원 사진 전파는 기존 동작을 유지한다.

## 검증

기존 프로필 브라우저 검증에 새 펼침 동작, 탭 방향키·Home·End와 단일 Tab 진입점, 화면 크기 변경 후 설정 상태 유지를 반영했다. 로컬 API 응답을 고정한 fixture로 검사하며 운영 계정은 변경하지 않는다.

- 너비 320·375·390·414·768·844·1440px, 라이트·다크.
- 다섯 활동 분류와 URL 복원, 긴 이름·큰 수치, 사진 미등록·등록, 빈 활동.
- 편집 저장·취소·실패·뒤늦은 응답, 비밀번호 변경, 일반/Google 계정 탈퇴, 로그아웃.
- 숫자 기준선과 브랜드색, 가로 넘침, 목록 열 정렬, 초점과 접근 가능한 펼침 상태.

Hallmark의 자체 평가는 철학·위계·완성도·구체성·절제·구조 각각 4/5로 기록했다. 이는 설계 검토 메모이며 사용성 조사 점수를 뜻하지 않는다. 같은 앱에서는 테마 다양성보다 기존 디자인과의 일관성을 우선한다.
