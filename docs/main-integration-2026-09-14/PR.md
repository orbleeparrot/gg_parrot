리더보드와 뉴스 페이지 진입 때 반복되던 계산·수집 대기와 DB 조회를 줄이고, 회원 전환과 데이터 변경 후 낡은 캐시가 표시되는 문제를 수정합니다. 현재 작업 브랜치의 빌더 개선까지 포함하며, 최신 main의 복수 종목 페이퍼 트레이딩·일일 퀘스트·실행기 v7 출처/로그·헤더 회원 키 기능과 통합했습니다.

- 리더보드 순위를 백그라운드에서 계산해 DB snapshot으로 제공하고 채팅은 커서로 증분 조회합니다.
- 뉴스를 준비되는 기사부터 게시하며, 기존 뉴스 테이블 업그레이드와 갱신 실패 시 기사 유지 처리를 포함합니다.
- 계정별 작업 저장소, 공개 데이터 응답 재사용·백그라운드 갱신·실패 backoff·용량 제한, 개인 API no-store, 정적 파일/PWA 정책을 적용합니다.
- 빌더의 종목 검색, 포트폴리오 카드, 화면과 일치하는 카드 이미지 저장을 반영합니다.
- main 통합 중 확인한 퀘스트 잔액 덮어쓰기/중복 지급, 회원 키 두 패널 재발급 동기화, 비정상 서명에 의한 500, 신규 개인 테이블 권한·탈퇴 정리를 보완합니다.
