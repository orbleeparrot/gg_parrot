# 뉴스 유형·내부 유입·AI 단계 분리

## 적용 범위

- 코인동향의 기본 목록은 `보도 기사`. `커뮤니티 의견`과 `전체` 필터를 제공한다.
- 기존 콘텐츠 유형, 커뮤니티 게시글 ID, Binance Square 출처를 사용해 분리한다. 추가 AI 분류 호출은 없다. 출처 기반 구분이지 기사 내용의 사실 검증이나 모든 광고의 자동 탐지는 아니다.
- 기사와 커뮤니티 글에 콘텐츠 유형·출처를 함께 표시한다. 필터는 화면 목록에 적용하며 수집·번역 작업을 중단하거나 기존 데이터를 삭제하지 않는다.
- 관리자 사용자 지표에서 관리자 계정, 관리자 경로, 명시적 QA 방문 및 해당 세션을 기본 제외한다. 포함 토글은 별도 캐시 키를 사용한다.
- QA는 `/news?qa=1`로 브라우저에 표시하고 `/news?qa=0`으로 해제한다. 자동화 브라우저도 내부 방문으로 표시한다. 이미 쿼리가 있는 URL에는 `&qa=1`을 사용한다.
- 과거의 식별되지 않은 익명 QA 방문은 소급 판별하지 않는다. 사람 수로 오해하지 않도록 브라우저 수와 로그인 계정 수를 따로 표시한다.

## 관리자 뉴스 상태 읽기

- 기사 수집: 수집 실행 기록의 마지막 성공·오늘 저장 행·수집 실패와 현재 작업 점유를 표시한다. 대기/오류는 종목 수집 상태 기준이다. 예정된 모든 공개 뉴스 범위를 대기 기사 수로 추정하지 않는다.
- 제목 번역 / 커뮤니티 본문 요약: 현재 모델·프롬프트 버전의 저장 상태만 집계한다. 구 Gemini 결과는 이 단계 표에 섞이지 않는다.
- 오늘 완료는 현재 저장된 성공 결과 중 오늘 갱신된 수다. 번역은 고유 제목, 본문 요약은 게시글·본문 단위라 종목별 기사 저장 행 수와 다르다.
- 처리 중은 유효한 작업 점유를 뜻하며 외부 API가 실제로 진전 중이라는 보장은 아니다. 만료된 점유는 대기로 분류한다.
- 오류 작업 수는 현재 오류 상태의 작업 수이고, 오늘 실패는 누적 호출 실패 수다. 같은 작업 재시도로 숫자가 다를 수 있다. 오류 작업에는 재시도 대기와 한도 소진이 포함된다.
- 오늘의 시장 요약은 오늘 KST 공유 결과의 존재를 별도로 표시한다. 어제 성공이 있어도 오늘 결과가 없으면 `오늘 요약 없음`이다. 별도 상태가 저장되지 않는 대기/처리 중/오류 개수는 `—`로 표시한다.
- 기존 보강 엔진의 포괄적인 `지연` 행 대신 위 단계별 표를 사용한다. 기존 보강 대기·포기·예산 집계는 유지한다.

## 검증

- 격리된 SQLite / 외부 네트워크 차단 환경에서 백엔드 전체 2,325개 통과. 추가 회귀 테스트 이후 관리자 관련 58개 통과.
- 프론트 단위 테스트 424개 통과, Vite 프로덕션 빌드 통과. 기존 500 KB 초과 청크 경고는 남아 있다.
- Playwright에서 1440px·390px 화면: 기본 기사 필터, 커뮤니티 필터, 출처/안내, 내부 방문 토글, 기간 전환, 단계별 표 검증 통과. API 응답은 모두 로컬 가짜 응답이며 운영 계정·방문 기록을 생성하지 않는다.
- 브라우저 재검증: 로컬 Vite를 `VITE_API_PROXY` 설정과 함께 실행하고 `frontend/tests/newsAdminSeparationBrowser.smoke.py` 실행. 기본 주소는 `http://127.0.0.1:5183`이며 모든 API는 테스트가 가로챈다.

## 변경하지 않은 것

운영 배포, DB 스키마·RLS, API 키·모델·호출 한도, 실행기 버전은 변경하지 않았다. 번역 검증의 오탐이나 모델 출력 한도 때문에 발생하는 실패를 직접 수정한 것은 아니다.
