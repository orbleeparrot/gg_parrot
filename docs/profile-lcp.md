# 프로필 이미지 LCP 개선 — 2026-09-10

프로필의 큰 사진은 `/api/me/dashboard`가 매크로·판매·포인트·게시글 내역을 모두 반환한 뒤에야 DOM에 추가됐다. 헤더에서는 같은 사진을 이미 다운로드했어도 프로필 본문은 전체 스켈레톤만 표시했다. 프로필 이미지는 업로드 시 256×256 WebP로 정규화되고 있었다.

## 변경

- 로그인 상태에 있는 사진·이름·소개·가입일을 즉시 표시한다. 저장된 회원 정보가 없으면 헤더의 계정 조회가 이를 채우는 즉시 표시할 수 있다.
- 활동 내역과 등급은 별도로 로딩한다. 포인트·판매 수치는 대시보드 응답을 받은 뒤 표시한다.
- 활동 응답이 도착해도 사진 DOM을 교체하지 않는다. 활동 조회가 실패해도 프로필 설정과 로그아웃을 사용할 수 있다.
- 대시보드 결과는 요청 당시 토큰에 연결해 계정 전환 직후 이전 계정의 활동이 표시되지 않게 한다. 기존 응답 취소·프로필 편집 경쟁 상태 방어도 유지한다.
- 프로필 본문의 아바타만 높은 요청 우선순위를 부여한다. 공통 아바타 이미지에 너비·높이를 명시한다.
- 공개 이미지 조회 세션은 단일 읽기 질의를 AUTOCOMMIT으로 처리해 트랜잭션 왕복을 줄인다. 연결 반환 시 격리 수준이 복원된다. 이미지 교체·삭제의 트랜잭션과 기존 버전 URL·캐시 정책은 유지한다.

다운로드 이후 표시 지연은 [Chrome의 LCP 최적화 가이드](https://web.dev/articles/optimize-lcp)가 구분하는 `element render delay`에 해당한다.

## 측정

사용자가 보고한 2.52초는 사용자 브라우저 측정이다. 아래 표는 별도의 로컬 검증이며 그 값을 직접 재측정한 결과가 아니다.

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 개발 서버의 같은 공개 아바타 API, 원격 PostgreSQL | 753 / 756ms | 380 / 379ms |
| 프로필 이미지 LCP, 1440px | 1,728ms | 260ms |
| 프로필 이미지 LCP, 390px | 1,604ms | 168ms |

이미지 API 표본은 공개 게시판에서 사용 중인 3,428바이트 이미지의 GET 요청 2회씩이다. 파일을 변경하거나 실제 계정으로 로그인하지 않았다.

LCP 표본은 프로덕션 빌드를 로컬 HTTP 서버로 제공하고, 가짜 로그인 정보와 256px 이미지로 실행한 Chromium 검사다. 활동 API 요청을 보류한 뒤 1.4초가 지나면 응답하도록 했다. 실제 데이터베이스와 외부 API는 사용하지 않았다. 변경 전후 최종 LCP 요소는 모두 `.me-avatar img`다. 변경 전에는 이미지 전송이 약 57–77ms에 끝나도 활동 응답 전에는 본문 사진이 없었고, 변경 후에는 응답 전에 사진이 표시됐다.

자동화 브라우저의 첫 컨텍스트에서는 앱과 별개로 첫 페인트가 약 3초까지 밀리는 현상이 있어, 위 비교는 빈 로컬 문서를 먼저 그려 브라우저를 준비한 후 새 컨텍스트에서 측정했다. 앱 리소스를 미리 읽거나 컨텍스트의 캐시를 공유하지 않았다. 초기 브라우저 표본과 최종 비교를 섞지 않았다. 표의 LCP는 각 조건의 단일 표본이며 운영 환경 백분위 지표가 아니다.

## 검증

- 수정 전 빌드에서 `profileLoadingBrowser.smoke.py`의 활동 응답 전 사진 표시 검사가 실패함을 확인했다.
- 수정 후 같은 검사 4개 통과: 390px/1440px에서 사진 선표시, 활동 수치 대기, 사진 DOM 유지, 계정 전환, 활동 조회 오류와 로그아웃.
- 기존 프로필 브라우저 검사 13개 통과: 모바일·PC, 밝은/어두운 테마, 수치 정렬, 사진 편집·삭제·재접속, 늦은 응답, 계정 전환, 비밀번호 변경, 회원 탈퇴.
- 격리된 SQLite에서 아바타·프로필 설정·대시보드·요청 단위 세션 테스트 30개 통과.
- 프로필 이미지 API·텍스트·성능 자산 Node 검사 및 Vite 빌드 통과.

로딩 회귀 검사 재실행:

```sh
cd frontend
npm run build -- --outDir /tmp/ggp-profile-lcp-build
FRONTEND_BUILD=/tmp/ggp-profile-lcp-build BROWSER_EXECUTABLE_PATH=/path/to/chromium python tests/profileLoadingBrowser.smoke.py
```

운영 배포나 인프라 변경은 수행하지 않았다.
