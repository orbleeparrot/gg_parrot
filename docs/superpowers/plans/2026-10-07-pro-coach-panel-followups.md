# 코치 패널 — 보류한 발견 (2026-10-07)

코치 패널과 국내 매크로 파일 실행을 내보낸 뒤 남긴 것들. 차단이 아니어서 그 자리에서 고치지
않기로 판정한 항목이고, 판정 근거를 함께 적었다.

## 사용자가 맞닥뜨릴 수 있는 것

### 1. 코치의 종목 입력이 거래소 모양을 보지 않는다

업비트 코치에 `BTCUSDT` 를 적으면 폼 검증에서 막히는 폼이 나온다. 국내는 `KRW-BTC` 모양이다.
`placeholder` 는 거래소에 맞게 나오지만 입력값을 걸러 주지는 않는다.

판정: 전수 보증의 구멍은 아니다(입력형 노드는 대표값으로 고정해 증명했다). 사용자는 폼 검증에서
막히고 문구를 본다. `coach.py` 의 `_parse_symbols` 가 `answers["exchange"]` 를 보면 끝나는 일이다 —
작고 값어치 있는 후속.

### 2. v9 실행기에 국내 매크로 파일을 넣으면 세션 시작에서 426 이 난다

서버는 파일을 내줄 때 실행기 버전을 모른다. 세 화면(모의 다음 단계 상자 · 실행 판 행 아래 ·
프로 빌더 버튼 아래)에서 "실행기 v10 이상이 필요해요" 를 미리 말하고 시험으로 고정했지만, 안내를
지나치면 파일을 넣은 뒤에 알게 된다.

판정: 버전을 아는 자리는 세션 시작 하나뿐이고, 그 자리는 이미 한국어로 거절한다. 내려받기 때
막으려면 실행기가 미리 자기 버전을 알려 주는 경로가 필요하고 그것은 실행기 변경이다.

### 3. 코치 되돌리기가 이미 판에 넣은 값을 지우지 않는다

`onPatch` 는 병합이다. 되돌리면 그 질문을 다시 내고, 새 답이 같은 키를 덮어쓴다. 그래서 실제로는
남지 않지만, 되돌린 뒤 **대화를 그만두면** 그 턴이 넣은 값이 판에 남는다.

판정: 지우는 기능을 넣으면 "코치가 내 판을 비웠다" 가 되어 더 나쁘다. 판은 사용자 것이다.

### 4. 프로 빌더에는 빠른 실행이 없다

파일 내려받기만 있다. 빠른 실행(내 PC 실행기 직접 연결)은 매크로를 먼저 저장해야 하고, 프로
빌더에는 저장·등록 경로가 없다.

판정: 사용자가 범위를 "파일 내려받기 버튼만" 으로 정했다. 실행 판 전체를 프로 빌더로 옮기는 것은
별개 작업이다.

### 5. 코치가 규칙 B·D 를 제안하지 않는다

가격대(B)와 그리드(D)의 기본값이 BTC 시세에 묶여 있어, 다른 종목을 고른 사용자에게 맞지 않는 폼이
나온다. 그래서 후보에서 뺐다.

판정: 판에서 직접 고를 수 있다. 가격을 묻는 노드를 더하면 코치에도 넣을 수 있다.

## 설계·시험 쪽 빚

### 6. 잘못된 요청 본문은 영어 422 가 뜬다

코치 끝점이 pydantic 모델로 본문을 받으므로 모양이 틀리면 FastAPI 기본 영어 422 가 나오고,
`api.js:118` 이 그것을 날 JSON 으로 띄운다. ask 끝점은 dict 를 손으로 검사해 그것을 피한다.

판정: 프런트가 본문 모양을 정하므로 사용자가 닿지 않는다. 같은 모양으로 맞추는 것이 일관되지만
별개 작업이다.

### 7. 프런트 시험이 클릭 흐름을 증명하지 못한다

SSR 한 번이라 코치 패널의 클릭 흐름(선택지 → `coachAnswer` → `onPatch`), 입력 제출,
오류 경로(403/429/404/410)가 증명되지 않았다.

판정: 2/3 과 같은 한계다. 대신 **실제 화면 소스를 읽어** 단정하는 시험을 넣어 뒀다 —
2/3 에서 하드코딩 props 로 그린 시험이 "기능이 반대 화면에 들어간" 것을 674개 수트가 통과시켰고,
같은 종류의 다음 실수는 그 시험이 잡는다.

### 8. 서버 스키마 교차확인이 수트에 없다

전수 경로 시험이 만든 매크로 14,088개를 백엔드 `Macro.model_validate` 에 먹여 거부 0건을 확인했지만,
그것은 일회성 스크립트였고 수트에 남기지 않았다(그 시험 파일의 범위가 프런트 하나다).

판정: 프런트 전수 시험이 `validateDetailed`·`buildMacro` 로 같은 성질을 본다. 서버 쪽 교차확인을
수트로 만들려면 파이썬에서 폼을 만들어야 하고, 그것이 바로 피하려던 중복이다.

### 9. 압축 묶음 거절 문구가 두 곳에 글자로 있다

`realtrade.build_bundle` 안의 문구가 순환 import 를 피해 상수의 글자 사본으로 들어 있다
(둘이 같은지 시험이 본다).

판정: 시험이 어긋남을 잡는다. 한 곳으로 모으는 것은 import 구조를 건드리는 일이다.

### 10. H 의 `uses_invest_ratio` 곱이 지금은 늘 1.0 이다

마틴게일(H)이 코치에서 `wide`·`free` 조합에서만 나오므로 그 계수가 실제로 1.0 이 아닌 경우가 없다.

판정: 죽은 분기는 아니다(조합이 늘면 살아난다). 전수 시험이 그 표를 그대로 쓰므로 어긋나면 잡힌다.
