# 껄무새에게 물어볼까? — 종목 후보 제시 (v2) 설계

작성: 2026-09-23 · 상태: 승인 대기 · 선행: [2026-09-18-ask-parrot-design.md](2026-09-18-ask-parrot-design.md)

## 0. 한 줄 요약

"성향 → 시장 → 종목 → 기간 → 봉" 다섯 장을 "성향 → 시장 → **투자 기간** → **볼 수 있는 빈도**"
네 장으로 바꾸고, 그 답을 근거로 **종목 후보 3~4개를 선정 이유와 함께** 보여 준다. 하나를 고르면
지금과 같은 매크로 후보 3개가 나온다. 한 흐름 전체가 하루 횟수 1회다.

## 1. 왜 바꾸는가

코인 초보는 종목 선정 자체를 어려워한다. v1 은 "어떤 종목이 궁금해요?"라고 물어 인기 5개 중에서
고르게 했는데, 무엇을 골라야 할지 모르는 사람에게는 이 카드가 첫 번째 벽이 된다. 사람에 대한
질문(성향·기간·생활 패턴)을 늘리고 종목은 껄무새가 후보로 제시하는 편이 초보에게 맞다.

## 2. v1 원칙의 변경과 방어 (중요)

v1 은 **"종목 카드 외에 AI 가 종목을 고르는 경로 없음"** 을 법적 설계 원칙으로 두었다. v2 는 이
원칙을 의도적으로 되돌린다. 대신 아래 장치로 방어한다.

| v1 원칙 | v2 에서 | 방어 |
|---|---|---|
| 종목은 사용자가 고른 것만 | AI 가 후보를 제시 | AI 는 **규칙으로 만든 풀 안에서만** 고른다. 풀은 거래대금·변동폭 같은 객관 지표로만 만들고, 풀 밖 심볼은 서버가 버린다 |
| 숫자는 AI 가 만들지 않는다 | 그대로 유지 | 이유 문구에 들어가는 거래대금 순위·변동폭은 **서버가 계산해 붙인다**. AI 는 "왜 이 성향에 맞는지" 문장만 쓴다 |
| "추천" 표현 금지 | 그대로 유지 | 화면·API·프롬프트·로그 전부 "후보". 금지어 필터를 서버에서 강제 |
| 사용자가 최종 결정 | 그대로 유지 | 후보는 제시일 뿐, 고르는 것도 실행하는 것도 사람이 한다. "직접 고를래요" 경로를 남긴다 |
| 요청·결과 기록 | 강화 | 무엇을 후보로 보여 줬는지(`candidates_json`)까지 남긴다 |

고지 문구는 버전을 올린다 (`DISCLAIMER_VERSION = "ask-v2"`). 후보 목록 화면에도 결과 화면과
같은 고지를 붙인다.

## 3. 흐름

```
① 성향   ② 시장   ③ 투자 기간   ④ 하루에 볼 수 있는 빈도
                    ↓ 제출 — 하루 횟수 1회 차감은 여기서만
⑤ 종목 후보 3~4개 (+ 한 줄 이유) · "직접 고를래요"
                    ↓ 1개 선택 — 차감 없음
⑥ 매크로 후보 3개 (v1 과 동일)
```

### 3.1 카드 변경

| 카드 | v1 | v2 |
|---|---|---|
| ① 성향 | 안정형/균형형/공격형/단타형 | 그대로. 손실 감내(-10%/-20%/무제한)를 겸한다 |
| ② 시장 | 현물/선물 + 레버리지 | 그대로. 안정형은 현물 고정 |
| ③ 기간 | "어느 기간을 살펴볼까요" (백테스트 구간) | **"얼마나 길게 굴릴 거예요"** (투자 기간). 백테스트 구간은 서버가 변환 |
| ④ 봉 | "얼마나 자주 사고팔고 싶어요" | **"하루에 얼마나 자주 볼 수 있어요"**. 봉은 서버가 변환 |
| ⑤ 종목 | 인기 5개 중 최대 3개 | **후보 3~4개 중 1개**. 포트폴리오(다종목) 경로 제거 |

### 3.2 사람 답변 → 기술 값 변환 (서버)

투자 기간:

| 답변 | 백테스트 구간 |
|---|---|
| 며칠 | `1w` (최근 1주) |
| 몇 주 | `3m` (최근 3개월) · 단타형은 `1m`(최근 1개월) |
| 몇 달 | `6m` (최근 6개월) · 단타형은 `1m`(최근 1개월) |
| 길게 | `1y` (최근 1년) · 단타형은 `1m`(최근 1개월) |

단타형은 짧은 구간만 허용하므로 `SHORT_PERIODS`(`1w`·`1m`) 로 clamp 한다.

> 주의: 구간의 `1m` 은 **1개월**, 봉의 `1m` 은 **1분** 이다. 기존 코드의 표기를 그대로 쓴다.

볼 수 있는 빈도:

| 답변 | 봉 (일반) | 봉 (단타형) |
|---|---|---|
| 거의 못 봐요 | `1d` | `15m` |
| 가끔 봐요 | `4h` | `5m` |
| 수시로 봐요 | `1h` | `1m` |

v1 제약 유지 — 1분 봉은 백테스트 구간이 `1w` 일 때만. 단타형 + 수시로 + 구간이 `1w` 가 아니면
`5m` 로 낮춘다.

## 4. 후보 선정 — 하이브리드

### 4.1 1단계: 규칙으로 풀 만들기 (AI 없음)

바이낸스 24시간 티커 한 번 호출로 끝난다. `hotcoins.py` 가 쓰는 캐시를 재사용하므로 추가 비용이 없다.

1. USDT 페어만, 스테이블 기반·레버리지 토큰 제외 (`hotcoins` 기존 로직 재사용)
2. 거래대금 하한 미만 제거 (유동성)
3. 같은 응답의 `highPrice`/`lowPrice` 로 **일중 변동폭** `range_pct = (high - low) / low * 100` 계산
4. 성향별 정렬로 **8~12개 풀** 확정

| 성향 | 정렬 |
|---|---|
| 안정형 | 거래대금 상위 풀에서 `range_pct` 오름차순 |
| 균형형 | 거래대금 상위 풀에서 `range_pct` 중앙값에 가까운 순 |
| 공격형 | 거래대금 상위 풀에서 `range_pct` 내림차순 |
| 단타형 | 거래대금 최상위(슬리피지)로 좁힌 뒤 `range_pct` 내림차순 |

### 4.2 2단계: AI 가 풀에서 선별 + 이유

풀(심볼 + 거래대금 순위 + `range_pct` + 24시간 등락)과 성향·투자 기간·볼 빈도를 넘기고,
**풀 안에서만** 3~4개를 고르고 각 한 줄 이유를 쓰게 한다. 기존 Gemini 경로(`ai_runtime`)를 쓴다.

서버 검증 (전부 강제):

- 풀에 없는 심볼 → 버림
- 3개 미만이면 규칙 순위로 채우고, 4개 초과면 자른다
- 이유는 한 줄(80자) 초과 시 자름
- 금지어(`추천`, `보장`, `확실`, `무조건`, 수익률 숫자 약속) 포함 시 그 이유만 폴백 문구로 교체
- AI 실패·타임아웃 → **규칙 상위 4개 + 정해진 문구**로 폴백. 흐름은 멈추지 않는다

### 4.3 이유 문구 모양

숫자는 서버가 붙이고 문장만 AI 가 쓴다.

> **DOGEUSDT** · 거래대금 5위 · 하루 변동폭 4.2%
> 거래가 활발해서 사고팔 때 밀리지 않고, 변동이 커서 짧은 봉에서 신호가 자주 나와요.

폴백 문구는 성향별로 미리 정한 한 줄을 쓴다 (예: 안정형 → "거래가 가장 활발하고 하루 변동이
작은 편이에요").

## 5. API

### 5.1 `POST /api/ask/candidates` — 차감이 일어나는 유일한 곳

```
body: { risk_profile, market, leverage, invest_horizon, watch_frequency }
resp: {
  session_id,
  candidates: [ { symbol, base, reason, volume_rank, range_pct, change_pct } ],   // 3~4개
  manual_symbols: ["BTCUSDT", ...],   // "직접 고를래요" 목록
  remaining_today,
  disclaimer
}
```

- 하루 한도 검사 → 초과면 402/429 (v1 과 동일한 기존 경로, 포인트 추가 구매 포함)
- 세션 row 생성 = 차감
- AI 실패해도 폴백으로 200

### 5.2 `POST /api/ask` — 차감 없음

```
body: { session_id, symbol }
resp: v1 과 동일 (매크로 후보 3개 + 지표)
```

- 세션에서 답변을 꺼내 쓴다. 클라이언트가 성향·기간을 다시 보내지 않는다 (위변조 차단)
- `symbol` 은 후보 목록 또는 `manual_symbols` 에 있어야 한다
- 같은 세션으로 다른 종목을 다시 요청 가능 — 추가 차감 없음

### 5.3 남용 방어

- 세션당 `/api/ask` **최대 6회** (후보 4개 + 직접 고르기 여유). 초과 시 409
- 세션 **30분 만료**. 만료 후 요청은 410, 새로 물어봐야 한다

### 5.4 하위 호환

`/api/ask` 의 요청 모양이 바뀐다. 배포 직후 옛 번들을 캐시로 들고 있는 브라우저는 한 번 실패하므로,
`session_id` 가 없는 요청에는 "새로고침해 주세요" 문구를 담은 422 를 돌려준다.

## 6. 데이터 모델

`AskMacroSession` 을 확장한다 (새 테이블 없음). v1 에서는 결과가 나온 뒤 한 줄 기록했지만,
v2 는 **후보를 낼 때 미리 만들고** 나중에 결과를 채운다. 하루 한도는 이 row 를 세는 기존 방식
그대로라, "후보를 받는 순간 1회 차감" 이 자동으로 성립한다.

추가 컬럼 (마이그레이션 1개):

| 컬럼 | 뜻 |
|---|---|
| `candidates_json` | 보여 준 후보와 이유 (문의 대응·감사) |
| `chosen_symbol` | 사용자가 고른 종목 |
| `expires_ms` | 세션 유효 시한 |
| `ask_count` | 이 세션으로 매크로를 만든 횟수 (상한 6) |

`request_json` 에는 카드 답변(성향·시장·레버리지·투자 기간·볼 빈도)을 그대로 담는다.
`results_json`·`candidate_count`·`ai_used`·`elapsed_ms` 는 마지막 `/api/ask` 결과로 갱신한다.

## 7. 프론트 상태 머신

`askFlow.js` 의 순수 리듀서 구조는 유지한다.

```
phase: "cards"              카드 4장
     → "loadingCandidates"
     → "candidates"         후보 3~4개 + 직접 고르기
     → "loadingResults"
     → "results"            매크로 3개
```

- `answers`: `{ profile, market, leverage, horizon, watch, symbol }`
- `symbols[]` + `toggleSymbol` + `confirmSymbols` → **`symbol` 단일 + `chooseSymbol`** 로 교체
- `session` (id·만료·남은 호출 수) 을 상태에 둔다
- 뒤로 가기(카드 단계로) → 세션·후보·결과를 모두 버린다
- 결과의 "다른 종목으로" → `phase: "candidates"` 로 복귀, 세션 유지 (차감 없음)
- 결과의 "안전하게/공격적으로" → 성향이 바뀌면 후보가 달라지므로 **카드 단계로 돌아간다**.
  다시 제출할 때 새로 1회 차감되므로, 버튼에 남은 횟수를 함께 보여 준다

## 8. 손댈 파일

## 9. 테스트

백엔드 (신규 `backend/tests/test_ask_candidates.py`, 기존 `test_ask.py` 확장)

- 성향별 풀 정렬이 의도대로인지 (안정형=변동폭 낮은 순 등)
- 스테이블·레버리지 토큰·거래대금 미달이 풀에서 빠지는지
- AI 가 **풀 밖 심볼**을 냈을 때 버려지는지
- AI 가 **금지어**를 썼을 때 이유가 폴백으로 바뀌는지
- AI 가 2개만 냈을 때 규칙 순위로 채워 3개 이상이 되는지
- AI 예외·타임아웃 시 폴백으로 200 이 나오는지
- 차감이 `/api/ask/candidates` 에서 **딱 1회**, `/api/ask` 에서 **0회**
- 세션 6회 상한(409), 30분 만료(410), 풀·수동 목록 밖 심볼 거부
- `session_id` 없는 옛 요청이 안내 문구와 함께 422

프론트 (`frontend/tests/askFlow.test.js` 재작성)

- 카드 4장 전이, 뒤로 가기 시 세션·후보·결과 초기화
- 후보 단계에서 1개만 선택되는지
- "다른 종목으로" 가 세션을 유지하는지
- "안전하게/공격적으로" 가 카드 단계로 돌아가는지
- 단타형 + 수시로 + 구간이 1주가 아닐 때 봉이 5분으로 낮아지는지

## 10. 범위 밖

- 투입 금액 질문 (이번에 넣지 않기로 함)
- 여러 종목 묶음 제시 / 포트폴리오 매크로 — v1 경로째 제거
- 후보에 업비트·빗썸 종목 포함 (바이낸스 USDT 페어만)
