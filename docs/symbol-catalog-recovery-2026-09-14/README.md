# 운영 종목 조회 및 게이트웨이 오류 복구

검증 기준은 PR #75로 통합된 `0a3636f`입니다. 아래 운영 관측은 수정 배포 전 기록이며, 로컬 회귀 검증과 구분합니다.

## 확인된 문제와 수정

- 운영 `/api/symbols`가 503을 반환해 DOT 검색이 실패했습니다. 종목 조회만 `BINANCE_API_BASE` 설정을 무시했고, 현물·선물 중 하나라도 실패하면 전체 목록 조회를 실패시켰습니다. 설정된 공개 데이터 주소를 사용하고 시장별 정상 목록을 별도로 보관하도록 수정했습니다. 한 시장만 조회할 수 있으면 검증된 종목과 해당 시장의 지원 여부를 반환하고 빠르게 재조회합니다.
- 현물 exchangeInfo 요청에 공식 필터를 적용했습니다. 공개 미러에서 원본과 비교한 결과 17,589,083바이트에서 2,477,677바이트로 줄었고, DOT를 포함한 거래 가능 USDT 현물 490개는 동일했습니다. 이는 Render 메모리 사용량 측정이 아닙니다. [Binance 공식 파라미터](https://developers.binance.com/docs/binance-spot-api-docs/rest-api/general-endpoints)
- 검색 실패 후 재시도 버튼을 누르면 입력창의 blur 타이머가 결과창을 닫았습니다. 재시도 중 포커스를 유지하도록 수정했습니다.
- 502·503·504의 HTML 오류 응답을 일반 HTML 페이지 라우팅 문제로 잘못 안내했습니다. 실제 상태 코드를 유지하면서 일시적인 연결 오류로 안내합니다. GET에만 500ms, 1500ms 간격으로 최대 두 번 재시도하고, 취소와 전체 제한시간을 유지합니다. JSON 503·401·429와 변경 요청은 자동 재시도하지 않습니다.
- 프로필에 수동 재시도를 추가했습니다. 종목 조회는 기본 25초, 프로필 조회는 15초 제한시간을 두어 무한 로딩을 방지합니다.

## 운영 관측

- `production-before.json`: 대부분의 API는 200 JSON, 미인증 프로필은 401 JSON, 종목 목록만 503 JSON이었습니다.
- `production-builder.json`과 `production-builder.png`: 실제 운영 빌더에서 DOT 검색 실패를 재현했습니다. 같은 탐색에서 차트 가격이 LCP 요소였고 4.356초였습니다. 새 익명 Chromium의 단일 실험실 측정으로, 사용자가 보고한 6.09초를 대체하거나 개선을 입증하지 않습니다.
- 추가 `production-builder-timing.json`에서는 LCP 2.688초, 최초 봉 수신 완료 0.420초, 첫 가격 DOM 표시 2.577초였습니다. 0.582초부터 약 1.996초짜리 메인 스레드 작업이 관측되어 데이터 대기 외의 렌더링 병목도 확인했습니다. 첫 live 요청과 가격 변경은 LCP 이후였습니다. 서버 오류 수정만으로 LCP 개선을 달성했다고 판단하지 않습니다.
- 사용자가 제공한 Render 로그: 2026-09-14 07:54:57 UTC 배포 시작, 07:55:41 애플리케이션 기동 완료, 07:55:43 health 200 및 서비스 live. 이후 캔들·김치 프리미엄 200, 07:56:22 종목 목록 503이 기록됐습니다. 제공된 구간에 OOM이나 기동 실패는 없습니다. 동시 502는 배포 중 연결 공백과 부합하지만, 기존 인스턴스 종료 시점·502 요청 시각은 로그에 없어 정확한 공백 구간은 확정하지 않습니다. 원본 로그의 IP 등은 저장하지 않았습니다.
- 운영 계정으로 로그인한 프로필 조회는 수행하지 않았습니다. 계정 동작은 아래 격리된 브라우저 회귀 검증으로 확인했습니다.

## 검증

- 전체 백엔드: 1,899개 통과. 임시 SQLite, 외부 네트워크 차단. `backend-tests.json`.
- 전체 프런트엔드 Node 테스트: 302개 통과. 게이트웨이 복구 관련 신규 21개 포함.
- Vite 프로덕션 빌드 성공. 기존 500kB 초과 청크 경고는 남아 있습니다.
- 동일 최종 빌드의 브라우저 시나리오 20개 통과: 프로필 10개, 종목 재시도 2개, 계정 분리 8개. 모바일 390px·데스크톱 1440px에서 502 자동 복구, 재시도 소진 후 수동 복구, 계정 전환, DOT 선택을 검증했습니다. API·WebSocket은 모두 fixture로 격리했습니다.
- 독립 소스 검토에서 시장별 캐시·계정 구분·재시도 포커스의 차단 이슈가 발견되지 않았습니다.

재현용 스크립트 `compare_spot_catalog.py`와 `probe_builder.py`는 명시적으로 실행할 때만 공개 GET 요청을 보냅니다. 일반 회귀 테스트는 운영에 연결하지 않습니다.
