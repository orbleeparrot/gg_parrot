# 차트 도구줄 정렬

봉 간격과 확대·축소 버튼을 구간 등락의 글자 기준선에 맞추고, 두 영역 사이 간격을 14px에서 28px로 늘렸습니다. 폭이 부족하면 조절 영역은 다음 줄로 내려갑니다.

- [데스크톱 확인 화면](toolbar-desktop.png)
- [모바일 확인 화면](toolbar-mobile.png)
- [브라우저 확인 결과](report.json): 1440·1100·390·320px에서 화면 넘침 없음, 데스크톱 가로 간격 28px, 실행 오류 없음.

API는 로컬 테스트 응답으로 대체했으며 화면의 시세는 검증용 값입니다. 프런트엔드 빌드도 통과했습니다.
