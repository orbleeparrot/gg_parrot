# 조건 패널 가독성 확인

- 입력칸 36px, PC 입력값 14px, 라벨 13px, 도움말 12px. 모바일 입력값은 자동 확대 방지를 위해 16px.
- 기본 2열을 유지하고 긴 선택지·체크 항목은 전체 너비 사용.
- A–K × PC(1440px)·모바일(390px) × 밝은·어두운 테마: 44개 조합 확인.
- 같은 행 입력칸의 위쪽 정렬, 선택지 잘림, 숫자·단위 겹침, 패널 밖 넘침 확인.
- `0.00001234` 가격 입력, 표준편차 입력·포커스, 프로덕션 빌드 확인.

스크린샷의 시세·계정·자금은 로컬 검증용 응답이며 실제 회원 데이터가 아닙니다.
