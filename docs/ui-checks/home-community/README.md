# 메인 게시판 홍보 히어로

홍보 문구·캐릭터·게시판 모형을 사용한 히어로입니다. 게시글 목록 위에 `게시글 미리보기`를 표시하고, 목록만 옅은 무채색으로 처리해 클릭 대상과 구분합니다. 실제 게시판은 `게시판 둘러보기` 버튼으로 이동합니다.

데스크톱 목록은 움직이며 마우스를 올리면 멈춥니다. 모바일에는 세 개의 예시 글이 정지된 상태로 표시됩니다. 미리보기 글에는 링크나 버튼이 없으며 기본 커서를 사용합니다.

- [모바일 · 어두운 테마](home-390-dark.png)
- [모바일 · 밝은 테마](home-390-light.png)

`frontend/tests/homeMobileBrowser.smoke.py`로 320·390·768·1099px의 문서 스크롤과 넘침, 모바일의 정지된 목록, 게시판 이동, 기기별 시작 버튼, 데스크톱 캐러셀·목록의 호버 일시정지·화면 크기 전환을 확인합니다. API는 로컬 응답으로 대체했습니다.
