# 메인 게시판 소개

예시 글이 실제 게시물로 보이던 목록을 없애고, 게시판 캐릭터와 질문·비교·기록 안내로 바꿨습니다. 가상 작성자, 작성 시각, 댓글 수, 새 글 쓰기 모형, 페이지 번호와 목록 애니메이션을 제거했습니다. `게시판 둘러보기`는 실제 `/board`로 연결됩니다.

- [데스크톱](home-desktop-community.png)
- [모바일 · 어두운 테마](home-390-dark.png)
- [모바일 · 밝은 테마](home-390-light.png)
- [검증 결과](report.json)

`frontend/tests/homeMobileBrowser.smoke.py`로 320·390·768·1099px의 문서 스크롤과 넘침, 모바일의 정지된 안내, 게시판 이동, 기기별 시작 버튼, 데스크톱 캐러셀과 화면 크기 전환을 확인했습니다. 10개 검증과 프런트엔드 빌드가 통과했습니다. API는 로컬 응답으로 대체했습니다.
