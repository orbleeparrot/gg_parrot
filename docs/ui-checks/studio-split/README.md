# 조건 패널 너비 조절

조건과 차트 사이 세로선을 드래그해 너비를 조절합니다. 패널 내용이 420px 이상이면 2열, 그보다 좁으면 1열로 표시됩니다. 입력칸은 남은 너비를 채웁니다.

- 너비는 드래그를 마친 뒤 브라우저에 저장됩니다. 클릭·연속 클릭으로 너비가 바뀌지 않습니다.
- 경계선에 키보드 포커스를 두고 좌우 화살표로 조절할 수 있습니다. Home/End는 최소·최대 너비입니다.
- 모바일에서는 경계선을 숨기고 페이지 너비에 따라 입력 항목을 배치합니다.
- 차트·결과도 남은 폭에 반응하며, 좁은 결과 영역의 자산곡선과 표는 세로로 이어집니다.

## 검증

`frontend/tests/studioSplitBrowser.smoke.py`로 실제 포인터 드래그, 키보드 조절, 저장·복원, 창 크기 변경, A–K 전략, 모바일, 결과 재배치와 드래그 중단을 확인했습니다. [검증 결과](report.json)

클릭·연속 클릭에서 너비가 유지되는지, 마우스를 누른 동안 각 중간 위치가 이동 거리와 일치하는지 확인합니다. 드래그 중 작업 영역·차트 높이가 바뀌지 않고, 저장은 버튼을 놓은 뒤에만 수행되는지도 검사합니다.

API는 로컬 테스트 응답으로 대체했습니다. 화면의 시세·금액은 검증용 값입니다.
